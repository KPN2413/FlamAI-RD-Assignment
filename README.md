## 1. Problem

The supplied points are generated by the parametric curve:

```math
x=t\cos(\theta)-e^{M|t|}\sin(0.3t)\sin(\theta)+X
```

```math
y=42+t\sin(\theta)+e^{M|t|}\sin(0.3t)\cos(\theta)
```

with the constraints:

```math
0^\circ<\theta<50^\circ,\qquad -0.05<M<0.05,\qquad 0<X<100
```

and:

```math
6<t<60
```

The supplied `xy_data.csv` contains **1500 data points**.

The objective is to estimate the unknown parameters:

```math
\theta,\qquad M,\qquad X
```

such that the generated parametric curve matches the supplied points as closely as possible.

---

## 2. Key Mathematical Observation

Define:

```math
a=e^{M|t|}\sin(0.3t)
```

The original equations can then be written as:

```math
x-X=t\cos\theta-a\sin\theta
```

and:

```math
y-42=t\sin\theta+a\cos\theta
```

This has the structure of a two-dimensional rotation:

```math
\begin{bmatrix}
x-X\\
y-42
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta & -\sin\theta\\
\sin\theta & \cos\theta
\end{bmatrix}
\begin{bmatrix}
t\\
a
\end{bmatrix}
```

Applying the inverse rotation gives:

```math
t=(x-X)\cos\theta+(y-42)\sin\theta
```

and:

```math
a=-(x-X)\sin\theta+(y-42)\cos\theta
```

For the correct parameters, every supplied point should therefore satisfy:

```math
-(x-X)\sin\theta+(y-42)\cos\theta
=
e^{M|t|}\sin(0.3t)
```

where:

```math
t=(x-X)\cos\theta+(y-42)\sin\theta
```

This converts the original curve-fitting problem into a **three-parameter numerical optimisation problem** involving only:

```math
\theta,\qquad M,\qquad X
```

Since the assignment specifies:

```math
6<t<60
```

all valid values of `t` are positive. Therefore, within the required interval:

```math
|t|=t
```

The implementation still uses `abs(t)` so that the code remains identical to the original mathematical definition.

---

## 3. Optimisation Method

The parameter estimation was performed in two stages.

### 3.1 Differential Evolution

A bounded **Differential Evolution** optimiser was first used.

This was selected because:

- only three unknown parameters need to be estimated;
- exact parameter bounds are known;
- it performs a global search;
- it reduces the risk of converging to a poor local optimum.

The search bounds were:

```math
0^\circ<\theta<50^\circ
```

```math
-0.05<M<0.05
```

```math
0<X<100
```

For each candidate parameter set, the inverse rotation was used to infer `t` and the oscillatory component `a`.

The objective function minimised the mean absolute model-consistency residual:

```math
r_i=a_i-e^{M|t_i|}\sin(0.3t_i)
```

Candidates producing inferred `t` values outside the required interval were strongly penalised.

---

### 3.2 Non-linear Least-Squares Refinement

The best result from Differential Evolution was then used as the starting point for a **non-linear least-squares refinement**.

This second stage improves the numerical precision of the estimated parameters.

The raw numerical solution obtained from the supplied dataset was approximately:

| Parameter | Raw fitted value |
|---|---:|
| theta (radians) | 0.523598303175 |
| theta (degrees) | 29.9999729322 |
| M | 0.0299999968731 |
| X | 54.9999982128 |

These values strongly indicate that the underlying generating parameters are:

```math
\boxed{\theta=0.5235983,\qquad M=0.03,\qquad X=55}
```

The very small difference between the raw fitted values and the rounded values is at numerical floating-point/data precision level.

## 4. Validation

The recovered rounded parameters were substituted back into the model and evaluated against the supplied dataset.

The resulting model-consistency errors were:

- **Mean Absolute Error:** `2.724699414370e-06`
- **RMSE:** `3.742511204099e-06`
- **Maximum Absolute Residual:** `1.641854418688e-05`

These extremely small residuals indicate that the recovered parameters reproduce the supplied data very closely.
